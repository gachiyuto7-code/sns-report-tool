# 訴求チェッカー 入力例（架空のコーヒー豆サブスク「MORI COFFEE」）

訴求軸（高・低で共通）を入力し、キャプションとクリエイティブだけを差し替えて試します。

## 訴求軸（共通）

| 項目 | 入力内容 |
|---|---|
| 主訴求 | 忙しい朝でも、挽きたての香りで1日がやさしく始まる |
| ターゲット | 20〜30代の働く人（朝が慌ただしい） |
| 期待する行動（CTA） | プロフィールのリンクから初回お試しセットを注文 |
| 媒体 | Instagram |
| トーン＆マナー | 落ち着いて、やさしく、押しつけない |
| 訴求を表すキーワード（詳細設定） | 朝, 挽きたて, 香り, 初回お試し |
| 必須要素（詳細設定） | 初回お試しセット, 500円, プロフィールのリンク |

## 高得点を狙う例

クリエイティブ：`sample-high.png`（画像）／`sample-high.mp4`（動画）

キャプション：

```
朝の5分を、少しだけ丁寧に。

挽きたての香りが立ちのぼる瞬間は、慌ただしい朝のささやかなごほうびです。
MORI COFFEEは、焙煎したてのコーヒー豆を毎月お届けします。

はじめての方には、初回お試しセット（500円）をご用意しました。
気になった方は、プロフィールのリンクからのぞいてみてください。

#朝コーヒー #挽きたて #コーヒーのある暮らし #MORICOFFEE
```
