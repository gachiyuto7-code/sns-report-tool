訴求チェッカー通信なし・ブラウザ内で完結

訴求軸を先に決めて、画像・動画・キャプションがその訴求に合っているかを確認します。ジャンルを問わず使えます。初期状態では外部へデータを送信しません。

1訴求軸を入力

ここが評価の基準になります。具体的に書くほど、判定の精度が上がります。

詳細設定（任意）

2投稿内容を入力

キャプションは貼り付けでもファイルでも入力できます。クリエイティブは画像・動画を複数入れられます。

対応：.txt / .md / .csv / .html / .docx。Googleドキュメントは「ファイル → ダウンロード → Microsoft Word（.docx）またはプレーンテキスト（.txt）」で保存したものを読み込めます。
ここにファイルをドラッグ＆ドロップ、またはクリックして選択
画像：JPG / PNG / GIF / WebP　動画：MP4 / MOV / WebM
補足（任意）：AIが読み取る内容を自分でも書く場合

Gemini直接連携（任意・外部通信あり）

オンにすると、コピペなしでこのツールが画像・動画のコマ・テキストを評価に送り、結果を自動で表示します。

オンにすると、入力したキャプション、画像、動画のコマ画像がGoogleのGemini APIへ送信されます。
社内でAPIの利用・未公開クリエイティブの送信が許可されているか、必ず確認してから使ってください。APIキーはこのページを閉じると消え、保存されません。

ルールチェックスコア（100点満点）

訴求の反映、CTA、表現リスク、文章の品質、媒体への適合をルールで採点します。内容が訴求に合っているかは、Geminiによる評価で確認します。

チェック辞書を編集

編集内容はこのブラウザにだけ保存されます。

3Geminiで評価する（コピペ方式）

① 下の指示文をコピー → ② Geminiに貼り付け、画像・動画ファイルも一緒に添付 → ③ 返ってきた結果を、次の欄に貼り付けます。


    

    
動画が大きくて添付できない場合は、各動画カードの「コマ画像を保存」で作った画像を代わりに添付できます。公開前のクリエイティブをGeminiに入れてよいかは、社内の規定に従ってください。

      総合スコアの出し方
      
    
        
  • 内容スコア（AI・80%）：訴求との一致45点、行動の見込み35点の配点で、AIが7項目を0〜5点で採点し、100点に換算します。
    • 
        
  • ルールチェック（20%）：キーワード、NGワード、表記ゆれ、文字数など、機械的に判定できる項目の点数です。
    • 
        
  • 上限ルール：主訴求の伝達が2点以下なら総合は59点まで、AIが重大リスク（誇大・虚偽・権利侵害のおそれなど）を指摘したら69点までに抑えます。他が良くても、訴求がずれた投稿に高得点が付かないようにするためです。
